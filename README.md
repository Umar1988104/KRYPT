# KRYPT

AI-powered scam & phishing message detector — paste a suspicious SMS,
WhatsApp message, email, or link, and get an instant verdict with a plain
explanation.

Built for Smart India Hackathon 2026.

## Features

- Instant verdict: Safe / Suspicious / Phishing, with a confidence score
- Explains *why*, in plain language — not just a yes/no
- Tuned for scam patterns common in India (fake UPI requests, courier scams,
  fake KYC messages, etc.)

## Tech Stack

- HTML, CSS, JavaScript — no framework, no build step
- AI language model API for the analysis (no custom-trained ML model, no
  database, no backend server)

## Getting Started

1. Clone or download this repo
2. Open `index.html` in your browser
3. On first load, enter your API key when prompted (stored only in your
   browser)
4. Paste a message and click **Analyse**

## Deployment

Deployed via GitHub Pages: **Settings → Pages → Deploy from branch → main →
/(root)**.
